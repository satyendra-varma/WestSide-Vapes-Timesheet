# WestSide Vapes Timesheet: instructions for Claude

Mobile-first shift timesheet, roster, stock/customer-request list and cash count for WestSide Vapes
(Kerrisdale). React + Vite + Tailwind on GitHub Pages; data in a Google Sheet behind an Apps Script web
app. Hours drive payroll and the app holds customer phone numbers: correctness and privacy beat speed.

## Start of every session
Read `CLAUDE.md`, `docs/PLAN.md`, `docs/DECISIONS.md` and the latest entry in `docs/PROGRESS.md`.
Use `docs/PROJECT.md` (architecture, sheet layout, API contract) and `docs/QA.md` as reference.

## Rules
1. **Never touch the deploy branch.** Never push to, merge into, or modify `main` (or `gh-pages`), and
   never change the GitHub Pages deploy workflow. Only the owner merges to `main`.
2. **Branches:** `dev` is the long-lived integration branch. Each phase gets its own branch
   `phase/<id>-<name>`, cut from `dev`. Merge it into `dev` locally once build and tests pass. Push
   `dev` and phase branches to origin as backup.
3. **One phase per branch.** Audit briefly, write the phase plan into `docs/PLAN.md`, then implement.
   In interactive sessions, wait for the owner's OK before editing. In unattended runs, the phase list
   in `PLAN.md` is pre-approved.
4. **Build + tests before every commit:** `npm run lint`, `npm run build` and `npm test` must all pass.
   Never commit a red build. Make small, logical commits.
5. **Update the docs with every commit:** a dated `docs/PROGRESS.md` entry (Current phase / Done /
   Next step / Known problems), plus `PLAN.md` ticks, `DECISIONS.md`, `QA.md`, `PROJECT.md` and
   `MORNING_CHECKLIST.md` as needed. A session can end at any moment.
6. **Never commit secrets, PINs, tokens, signing keys, or real customer or employee data.** Mock and demo
   data use fake names. Never hardcode a PIN.
7. **The app never calculates pay.** No hourly rates, no money derived from hours. The only money
   feature is the cash count, in integer cents.
8. **Hours are integer minutes** (`src/utils/hours.ts`), converted to hours only for display.
9. **Customer data:** minimal fields, React state only (never localStorage, sessionStorage, the service
   worker cache, or logs), and never in error or audit text.
10. **Sheet changes are additive.** Never delete or move existing columns without a migration note in
    `docs/PROJECT.md`.
11. **Backend source:** `apps-script/src/*.js`; `apps-script/Code.gs` is generated by
    `npm run build:gas` and checked by a test. Claude can't deploy Apps Script or reach the real
    Sheet; test against the mock backend (`npm run mock`). Owner actions go in
    `docs/MORNING_CHECKLIST.md`.
12. Don't add features beyond the plan. If something is ambiguous, pick the safer option and record it
    in `docs/DECISIONS.md`.

## Commands
- `npm install`
- `npm run lint` (tsc), `npm run build`, `npm test`
- `npm run build:gas`: regenerate `apps-script/Code.gs`
- `npm run mock`: local mock backend on http://localhost:8787
- `npm run dev`: app at http://localhost:3000/WestSide-Vapes-Timesheet/ (set `VITE_APPS_SCRIPT_URL`)
